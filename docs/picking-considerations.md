# 피킹 고려사항

- 그리퍼 열림 시 손가락이 주변 상품에 닿는지 확인한다. 접근 높이에서의 열림 폭과
  회전 시 손가락이 지나가는 범위를 주변 상품 배치와 함께 확인한다.
- 카메라는 상품을 놓는 바닥을 비추는 고정형이다. 상품의 긴 축 방향과 폭을 사용하려면
  OBB 또는 윤곽과 깊이 또는 파지 높이 평면을 사용해 두 끝점을 로봇 Base로 변환한다.
  손가락이 벌어지는 축을 상품의 긴 축과 맞춘다. 목표 폭은 실측한 mm ↔ 펄스 보정이
  있어야 적용할 수 있다. 폭이 실측 유효 범위를 벗어나면 해당 파지를 진행하지 않는다.

## RFID 통합 시험 입력

리더기 노드가 `/warehouse/rfid/uid`에 `std_msgs/msg/String`으로 현재 판독 UID를
발행해야 한다. 라벨 위치에서 수신 대기를 시작한다. 기본 대기 시간은 2초다.
빈 문자열은 판독 실패로 처리한다. 타임아웃·잘못된 UID·미등록 UID는 스캔 접근점으로
후퇴한 뒤 홈으로 복귀한다. 후퇴 명령이 실패하면 홈 이동을 이어서 보내지 않는다.
리더기 노드의 실제 판독 연결과 고정 카메라의 비전 연동은 별도 작업이다.

운영 노드와 RFID 토픽 설정은 [RFID 단일 상품 피킹 운영](operations.md)을 참고한다.
